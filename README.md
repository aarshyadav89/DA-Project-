# 📊 YouTube Content Performance at Scale

### Descriptive Data Analytics Project

##  Project Overview

This project analyzes YouTube video performance data to understand viewership trends, audience engagement, category-wise demand, and channel reach.

The project uses descriptive analytics techniques to transform video-performance data into meaningful insights that can help content creators, marketers, and analysts make data-driven decisions.

The analysis is based on a dataset containing **5,000 videos across 14 content categories**, covering the period from **January 2023 to August 2026**.

## Project Objectives

The main objectives of this project are:

* Identify the top-performing YouTube videos based on views.
* Analyze viewership trends over time.
* Understand audience engagement through likes and comments.
* Compare video performance across different content categories.
* Evaluate channel reach based on subscriber counts.
* Identify breakout videos from small and emerging channels.
* Define key performance indicators (KPIs) for monitoring content performance.
* Explore opportunities for future predictive analytics.

##  Key Performance Indicators (KPIs)

The report uses the following KPIs to evaluate YouTube content performance.

### 1. Total Views

Measures the total number of views generated by the videos.

**Formula:**

`Total Views = SUM(Views)`

### 2. Like Rate

Measures the proportion of views that resulted in likes.

**Formula:**

`Like Rate = (Total Likes / Total Views) × 100`

### 3. Engagement Rate

Measures audience interaction through likes and comments relative to views.

**Formula:**

`Engagement Rate = ((Total Likes + Total Comments) / Total Views) × 100`

### 4. Average Views per Video

Measures the average number of views generated by videos in a category.

**Formula:**

`Average Views per Video = Total Category Views / Number of Videos`

##  Key Findings

The analysis reveals several important insights:

* **Music leads in total views:** The Music category generated approximately 444.66 million views across 678 videos.
* **Gaming attracts substantial viewership:** Gaming generated approximately 182.53 million views across 750 videos.
* **Viral videos have a major impact:** The top-performing video received approximately 217.5 million views, demonstrating how a small number of videos can generate exceptionally high viewership.
* **Viewership fluctuates considerably:** Monthly views show significant spikes rather than consistent growth.
* **Engagement varies across categories:** Comedy and Gaming have relatively high average like rates, while News & Politics has a lower average like rate.
* **Small channels can achieve breakout success:** The report identifies 352 videos from small or emerging channels that reached the top quartile of video views.
* **Channel size influences average reach:** Videos from large channels receive higher average views, although smaller channels can still produce successful videos.
